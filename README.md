# sacure-automation

株式会社サキュレの業務自動化ツール置き場です。

## waste-calculator（廃棄物コネクト 案件量計算ツール）

「東京廃棄物コネクト」等の案件情報にある、下記のようなヒアリング文章を手集計せずに
月間の袋数と、お客様に提示する金額へ変換するための計算ツールです。

> 45Lのごみ袋で、可燃ごみ・生ごみが1日1〜2袋程度です。瓶・缶・ペットボトルは週に各1〜2袋程度、
> 段ボールは週に5〜10枚程度です。営業状況により増減します。

> 中野区の現ラボでは、45Lが1,2袋/日、週5回、不燃物週2日です。

### 収録ファイル

- `waste-calculator/index.html` — ブラウザで開くだけで使えるWeb版計算ツール。
  種別・袋サイズ・数量・頻度を入力する画面、「💰 金額提示」ボタンで切り替わる金額表示画面、
  「📖 使い方・単価表」画面の3画面構成です。入力画面はシンプルに保ち、単価は裏側で自動計算して
  金額提示画面にだけ大きく表示します。案件は複数登録できます。入力内容はブラウザのlocalStorageに
  自動保存されます。
- `waste-calculator/waste_calculator_template.xlsx` — 同じ考え方のExcelテンプレート版。
  「かんたん入力」シートに案件・種別ごとの数量を入力すると、月間量が数式で自動計算されます。
  使い方は「使い方」シートを参照してください（現在は金額計算には対応していません）。
- `waste-calculator/generate_template.py` — 上記xlsxテンプレートを生成するスクリプト（openpyxl使用）。
  テンプレートの構成やフォーマットを直したい場合は、このスクリプトを編集して再実行してください。

### 計算の考え方

1件あたりの数量（min〜maxの平均）に、頻度（「1回あたり数量 × 週の収集日数」）を掛けて
週あたり量を出し、さらに「1ヶ月あたりの週数」（既定値 4.35週 = 365日÷12ヶ月÷7日）を掛けて月間量を算出します。
Web版では「1ヶ月あたりの週数」は普段触る必要がないため、入力画面下部の「詳細な計算設定」を開かないと
表示されません（既定値のまま使えばOK）。

数量が明記されていない項目（例:「不燃物 週2日」のみで数量の記載がない場合）は、1回1袋と仮定しています。
実数が分かり次第、入力欄を修正してください。

数量min／数量maxは「1〜2袋」のように幅がある場合は両方入力、「2袋」のように1つだけの場合は
数量maxを空欄にすれば数量minの値だけで計算されます（Excel版・Web版どちらも対応）。

### 袋サイズと単価（Web版のみ）

可燃ごみ・生ごみ・不燃ごみ・瓶・缶・ペットボトルは、品目ごとに袋サイズ（45L／70L）を選べます。
袋サイズによって想定重量が変わるため、単価もサイズ別に持たせています（段ボールは「枚」単位のみ、
袋サイズの概念はありません）。

| 種別 | 袋サイズ | 想定重量 | 単価(円/kg) | 1個あたり単価 |
|---|---|---|---|---|
| 可燃ごみ | 45L | 5kg | 40円 | ¥200 |
| 可燃ごみ | 70L | 8kg | 40円 | ¥320 |
| 不燃ごみ | 45L | 3kg | 100円 | ¥300 |
| 不燃ごみ | 70L | 5kg | 100円 | ¥500 |
| 段ボール | (1枚) | 1kg | 35円 | ¥35 |

上記以外の種別（生ごみ・瓶・缶・ペットボトルなど）は単価が未確定のため金額計算に含まれません。
金額提示画面に「◯種別は単価未設定のため金額に含まれていません」という注意書きが出るので、
お客様にご案内する前に必ず内訳を確認してください。この表は `index.html` 内の `WEIGHT_TABLE` /
`PRICE_PER_KG` 定数から自動生成されており、「📖 使い方・単価表」画面でも同じ内容を確認できます。

### 金額提示（Web版のみ）

「💰 金額提示」ボタンを押すと、上記の単価をもとに計算した金額を大きく表示します。
初回手数料（既定 ¥3,000）は金額提示画面のチェックボックスで含める／含めないを切り替えられます。

**最低基本料金**：計算した月額が最低基本料金を下回る場合は、自動的にその金額まで引き上げます
（トラック訪問の固定費を下回らないようにするための下限額）。既定値は ¥5,000 ですが、
入力画面の各案件カードにある「最低基本料金」欄で**案件ごとに**変更できます。引き上げが発生した案件は、
金額提示画面に「内訳合計 ¥◯◯◯ → 最低月額 ¥◯◯◯ を適用」と表示されます。

（原価・粗利益の計算は現在は行っていません。金額提示のみのシンプルな構成です。）

### 自動生成される文面（Web版のみ）

金額提示画面に、コピーして使える文面が2つ表示されます。

- **見積前提条件**：品目（種別・袋サイズ・数量・頻度・月間想定量）と、案件カードに入力した
  「作業条件・特記事項」から組み立てた、お客様向けの前提条件文。契約時のトラブル防止のために使います。
- **見積内訳メール文面**：「可燃ごみ：1kg40円、月56袋想定(1袋5kgの場合)」のような、
  社内共有・見積確認メールに使える内訳文面。単価・重量の内訳と合計金額を記載します。

どちらも「📋 コピーする」ボタンでクリップボードにコピーできます。

### 使い方・単価表（Web版のみ）

入力画面の「📖 使い方・単価表」ボタンから、使い方の手順と上記の単価表をまとめたページを確認できます。

### 契約書の自動生成（Web版のみ）

金額提示画面の「📄 契約書をダウンロード（Word）」ボタンから、御社の実際の契約書雛形
「一般廃棄物収集運搬処理委託契約書」（第1条〜第15条＋別表）に準拠した契約書（.docx）を
ダウンロードできます。外部ライブラリを使わず、`index.html` 内でZIP（storeモード）とOOXMLを
直接組み立てて生成しています（`generateContractParagraphs` / `buildContractDocxBlob` 関数）。

条文本文・字下げなどの構成は雛形をそのまま踏襲し、以下のみ案件データから自動入力します。
- 作成日（本日日付）
- 甲（排出事業者）の名称＝企業名（住所・代表者は雛形どおり空欄）
- 別表：甲の事業所（店名＝企業名）、種類及び予定数量と単価（品目ごとに自動生成）
- 別表：契約期間（案件カードの「契約開始日」欄が入力されていれば、開始日〜1年後前日を
  自動計算。未入力なら雛形どおり空欄のまま出力）

第４条関係「搬入先」は品目によらず雛形と同じ固定文言、第３条関係「乙の事業範囲」は
区名部分を省いた汎用文言にしています。ダウンロードされるWordファイルは通常のテキストとして
生成しているため、数量・金額を含めどの項目も**ダウンロード後にWord上で直接修正可能**です。

ダウンロードファイル名はブラウザの都合上、英数字のみ（`keiyakusho_日時.docx`）にしています
（`download`属性に日本語ファイル名を指定すると、拡張子なしの`download`という名前に化けてしまう
挙動をChromiumで確認したため）。

### 入力バリデーション

数量・週数・最低基本料金の各欄に、マイナス値や数値として解釈できない文字列（空欄以外）を入力すると、
欄が赤く縁取られてエラーメッセージが表示されます。エラー中の値は計算には使われません（0として
扱われます）。エラー表示は画面を操作しても消えず、正しい値に修正するまで残り続けます。

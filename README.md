# sacure-automation

株式会社サキュレの業務自動化ツール置き場です。

## waste-calculator（廃棄物コネクト 案件量計算ツール）

「東京廃棄物コネクト」等の案件情報にある、下記のようなヒアリング文章を手集計せずに
月間の袋数・容量・概算料金へ変換するための計算ツールです。

> 45Lのごみ袋で、可燃ごみ・生ごみが1日1〜2袋程度です。瓶・缶・ペットボトルは週に各1〜2袋程度、
> 段ボールは週に5〜10枚程度です。営業状況により増減します。

> 中野区の現ラボでは、45Lが1,2袋/日、週5回、不燃物週2日です。

### 収録ファイル

- `waste-calculator/index.html` — ブラウザで開くだけで使えるWeb版計算ツール。
  画面上部の「かんたん入力／詳細入力」で表示を切り替えられます。
  - かんたん入力：種別・数量・頻度だけで月間袋数をサッと計算。
  - 詳細入力：単位・袋サイズ・重量(kg/個)・単価(円/kg)まで含めて、月間容量(L)・月間重量(kg)・概算料金も試算。
  案件は複数登録できますが、案件間の比較表は無く、案件ごとの合計だけを表示します。
  入力内容はブラウザのlocalStorageに自動保存されます。
- `waste-calculator/waste_calculator_template.xlsx` — 同じ考え方のExcelテンプレート版。
  「かんたん入力」「詳細入力」の2シートに分かれており、使い方は「使い方」シートを参照してください。
- `waste-calculator/generate_template.py` — 上記xlsxテンプレートを生成するスクリプト（openpyxl使用）。
  テンプレートの構成やフォーマットを直したい場合は、このスクリプトを編集して再実行してください。

### 計算の考え方

1件あたりの数量（min〜maxの平均）に、頻度（「1日◯袋 × 週の収集日数」または「週あたり◯袋」）を掛けて
週あたり量を出し、さらに「1ヶ月あたりの週数」（既定値 4.35週 = 365日÷12ヶ月÷7日）を掛けて月間量を算出します。

数量が明記されていない項目（例:「不燃物 週2日」のみで数量の記載がない場合）は、1回1袋と仮定しています。
実数が分かり次第、入力欄を修正してください。

### 料金の考え方（詳細入力）

単価は「1kgあたり」で入力する前提です（可燃40円/kg・不燃100円/kg・段ボール35円/kgを既定値として仮入力）。
ヒアリングデータには重量(kg)の記載が無いため、下記の実測値をもとにした目安で容量(L)・枚数から重量を換算しています。

- 袋モノ（可燃・不燃など）：45L ≈ 5kg、70L ≈ 8kg（線形換算、袋サイズが変わると自動で追従）
- 段ボール：1枚 ≈ 0.3kg

概算料金 ＝ 月間量 × 重量(kg/個) × 単価(円/kg)。重量はあくまで目安のため、実際の計量結果と差が出た場合は
「重量(kg/個)」欄を直接書き換えてください。
